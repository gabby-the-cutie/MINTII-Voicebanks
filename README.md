# 🌿 Mintii-Voicebanks

### Como usar e o que pode (e não pode) fazer com os voicebanks

Bem-vindo(a)! Os voicebanks do **Mintii-Voicebanks** foram feitos à mão pelo Gabby, para o **OpenUtau** e qualquer fork dele. Antes de sair cantando, leia com carinho as regras abaixo. Elas existem para manter os personagens e o trabalho por trás deles em segurança.

---

## 🌱 Como usar

1. **Baixe o instalador.** Use o botão de download do site do Mintii-Voicebanks.
2. **Abra o arquivo.** O instalador é um executável que se extrai sozinho. Se o Windows mostrar o aviso do SmartScreen ("O Windows protegeu o computador"), clique em **Mais informações → Executar assim mesmo**. Isso é normal para instaladores de autores independentes.
3. **Escolha os voicebanks.** Marque os que você quer e indique a pasta do seu OpenUtau.
4. **Instale.** Clique em instalar e aguarde terminar.
5. **Abra o OpenUtau** (ou o seu fork) e selecione o voicebank no seu projeto. Se ele não aparecer, reinicie o programa ou recarregue a lista de cantores.

---

## ✅ O que PODE

- **Usar os voicebanks no OpenUtau e em qualquer fork dele** para criar músicas, covers e projetos.
- **Dar crédito** ao Gabby e ao voicebank usado sempre que publicar algo com eles.
- **Redistribuir os voicebanks, mas só com permissão.** Peça antes e espere a resposta. Sem permissão, não compartilhe.
- **Mover para outro sintetizador, mas só se você for dono dele.** É preciso ter o sintetizador de forma legítima e legal. Versões piratas não valem.

> Os voicebanks não devem entrar em uma festa para a qual não foram convidados. Usar em outro programa é um convite que só vale para quem é dono da casa.

---

## ❌ O que NÃO pode

### 🚫 Conteúdo adulto
**Nenhum conteúdo adulto ou sexual envolvendo os personagens dos voicebanks**, incluindo **desenhos, ilustrações, fanarts, edições e qualquer outra forma de arte.**

Todos os personagens são retratados como **menores de idade**. Essa regra não tem exceção.

### 🚫 Discurso de ódio
Não use os voicebanks para discriminar, ofender ou promover ódio contra qualquer pessoa ou grupo.

### 🚫 Fins religiosos
Não use os voicebanks para pregação, propaganda ou qualquer conteúdo com fins religiosos.

### 🚫 Fins políticos
Não use os voicebanks para campanhas, propaganda ou conteúdo com fins políticos.

### 🚫 Redistribuir sem permissão
Não poste, reenvie ou hospede os arquivos dos voicebanks em outros lugares sem falar antes com o Gabby.

### 🚫 Levar para um sintetizador que você não possui
Não mova os voicebanks para programas que você não tem de forma legítima.
